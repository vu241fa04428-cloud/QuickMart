# QuickMart

A full-stack stationery and books shopping app built with React + Vite, Express, Node.js and MongoDB Atlas.

## Features
- Customer registration and login (bcrypt password hashing + JWT)
- Product catalogue, search and category filtering
- Product details
- Shopping cart (stored in MongoDB for logged-in users)
- Checkout with Cash on Delivery
- Customer order history
- Admin product create/update/delete and order status management
- Demo product seeder

## Requirements
- Node.js 20+ (Node 24 should work)
- npm
- MongoDB Atlas account (or local MongoDB)
- VS Code

## Project layout
- `frontend/` React application
- `backend/` Express API and MongoDB models

See `SETUP.md` for the exact setup commands and database connection instructions.
